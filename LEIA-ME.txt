TREM FINO ARTESANATO — SITE INICIAL

1. Abra index.html no navegador para visualizar o site.
2. Para ativar os botões de pedido, edite a variável WHATSAPP no final do index.html, incluindo 55 + DDD + número, somente dígitos.
3. Para cadastrar produtos reais, edite a lista 'produtos' no mesmo arquivo.
4. Para fotos, crie uma pasta 'imagens' e preencha o campo foto com, por exemplo, 'imagens/suporte-01.jpg'.
5. Publicação gratuita: crie um repositório público no GitHub, envie o arquivo index.html e as imagens e ative Settings > Pages > Deploy from a branch > main > / (root).
6. O endereço gratuito será https://USUARIO.github.io/NOME-DO-REPOSITORIO/ ou https://USUARIO.github.io/ se o repositório se chamar USUARIO.github.io.

Observação: produtos e textos são exemplos iniciais, não anúncios de peças verificadas. Nenhum WhatsApp foi configurado ainda.
